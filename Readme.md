# PrettyText - 文本格式化工具

一个美观、现代化的文本格式化桌面应用程序,支持 JSON、XML、CSV、YAML、HTML 等多种格式。

## ✨ 界面优化亮点

### 🎨 视觉美化
- **现代化配色方案**: 采用清新的浅色主题,带有专业的深色模式支持
- **优化的字体**: 
  - 代码编辑器使用 Consolas 10.5pt,更清晰易读
  - 界面文字使用微软雅黑 9pt,美观大方
- **无边框设计**: 文本框和树形控件采用无边框设计,更加简洁现代
- **统一的视觉语言**: 使用 Emoji 图标增强界面友好性

### 🎯 工具栏优化
- **逻辑分组**: 按功能将按钮分为以下组:
  - 核心操作: 美化、压缩、自动识别
  - 格式选择: 格式下拉框
  - 文件操作: 复制、打开、保存
  - 树形操作: 展开全部、折叠全部
  - 查找功能: 查找框及前后导航
  - 显示设置: 换行切换、主题切换
  - 历史记录: 历史记录下拉框
- **视觉分隔**: 使用分隔线清晰区分功能组
- **增强的按钮**: 
  - 主要操作按钮(美化)采用加粗字体和强调色
  - 所有按钮使用图标(Emoji)增强识别度
  - 简洁的符号按钮(◄/►/↵)节省空间

### 🌈 配色优化
- **亮色主题**:
  - 背景: 纯白色 (#FFFFFF) 和浅灰色 (#F5F5F5)
  - 工具栏/状态栏: 极浅灰 (#FAFAFA)
  - 强调色: 蓝色 (#007ACC)
  - 文字: 深灰色 (#282828)
  
- **暗色主题**:
  - 背景: 深灰色 (#202020, #1C1C1C)
  - 工具栏/状态栏: 中灰色 (#2D2D2D)
  - 强调色: 亮蓝色 (#0096FF)
  - 文字: 浅灰色 (#DCDCDC)

### 📊 状态显示优化
- **友好的状态提示**: 所有状态消息都带有图标
  - ✅ 成功操作
  - ❌ 错误提示
  - ⚠️ 警告信息
  - 🔍 查找操作
- **增强的统计信息**: 使用图标区分输入/输出统计
  - 📄 输入文本
  - 📝 输出文本

### 🎪 交互优化
- **TreeView 美化**:
  - 增加行高至 22px,更易阅读
  - 自定义线条颜色,暗色主题下更和谐
  - 优化字体大小
- **Tab 控件**: 统一字体样式,更加协调
- **自定义渲染器**: 实现专业的工具栏按钮悬停和按下效果

## 🚀 功能特性

- ✨ **多格式支持**: JSON、XML、CSV、YAML、HTML、纯文本
- 🔄 **双模式展示**: Text 模式和 Tree 模式自由切换
- 🎯 **自动识别**: 智能检测输入文本格式
- 📋 **灵活复制**: 支持全文、选中文本、节点内容复制
- 🔍 **强大查找**: 在 Tree 视图中快速查找和导航
- 📁 **文件操作**: 打开、保存、拖拽导入
- 📜 **历史记录**: 自动保存最近 20 条处理记录
- ⌨️ **快捷键支持**:
  - Ctrl+E: 美化
  - Ctrl+M: 压缩
  - Ctrl+O: 打开文件
  - Ctrl+S: 保存
  - Ctrl+F: 聚焦查找框
  - F5: 自动识别并美化
- 🌙 **主题切换**: 亮色/暗色主题一键切换
- 💾 **配置持久化**: 自动保存窗口大小、位置、主题等设置

## 🛠️ 技术栈

- .NET Framework 4.0
- Windows Forms
- C#

## 📝 使用说明

1. 在左侧输入框粘贴或输入需要格式化的文本
2. 点击"自动识别"或手动选择格式类型
3. 点击"美化"或"压缩"按钮
4. 在右侧查看格式化结果(Text 或 Tree 模式)
5. 使用复制按钮或右键菜单复制需要的内容
