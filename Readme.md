# PrettyText - 文本格式化工具

一个美观、现代的文本格式化桌面工具，支持 JSON、XML、CSV、YAML、HTML 等格式的
美化 / 压缩、树视图浏览、模型类生成。

## 🚀 功能特性

- ✨ **多格式支持**：JSON、XML、CSV、YAML、HTML、纯文本
- 🔄 **双模式展示**：Text（带语法着色）与 Tree 视图
- 🎯 **自动识别**：一键检测输入文本格式并美化
- 📦 **大文本支持**：左侧输入框可流畅处理 **几十 MB** 级文本（见下方"大文本说明"）
- 🔍 **查找定位**：在结果中查找并在文本 / 树视图中定位，回车查找下一个，Shift+回车查找上一个
- 📋 **灵活复制**：支持全文、选中文本、树节点文本 / 值
- 📁 **文件操作**：打开、保存、拖拽文件到窗口即可导入（自动识别 BOM / GBK 编码）
- 🌯 **自动换行**：一键切换长行的换行显示
- 📜 **历史记录**：自动记录最近 20 条处理内容（超长内容不写入磁盘）
- 🧬 **模型类生成**：根据 JSON / XML 生成 C# 或 Java 模型类
- 🌙 **主题切换**：亮色 / 暗色一键切换，工具栏与状态栏同步
- 💾 **配置持久化**：窗口尺寸位置、主题、字体、换行状态、历史记录自动保存到
  `%AppData%\PrettyText`

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+E | 美化 |
| Ctrl+M | 压缩 |
| Ctrl+O | 打开文件 |
| Ctrl+S | 保存结果 |
| Ctrl+F | 聚焦查找框 |
| F5 | 自动识别并美化 |
| Enter / Shift+Enter | 查找下一个 / 上一个（查找框内） |

## 🎨 界面说明

- **工具栏**：美化 / 压缩 / 自动识别 → 格式选择 → 复制 / 打开 / 保存 → 换行 / 清空
  → 树展开折叠 → 查找 → 历史记录 → 字体设置
- **状态栏**：左侧显示操作结果，右侧显示输入 / 输出统计（大文本自动切换为 KB / MB）
- **编辑器**：Consolas 等宽字体、无边框圆角容器、空内容时显示占位提示

## 🛠️ 技术栈

- .NET Framework 4.0
- Windows Forms + [AntdUI](https://gitee.com/antd-ui/AntdUI)（界面控件库）

## 📝 使用说明

1. 在左侧粘贴、输入文本，或直接把文件拖进窗口
2. 点击"自动识别"（F5）或手动选择格式
3. 点击"美化"（Ctrl+E）或"压缩"（Ctrl+M）
4. 在右侧 Text / Tree 标签页查看结果，需要时复制或保存

## 🧩 大文本说明（重要修复）

旧版本使用 `AntdUI.Input` 作为文本编辑控件，该控件为**逐字符缓存**的自绘实现，
实测插入 3 MB 文本需要约 8 秒、额外占用约 860 MB 内存，1 MB 也会卡顿并导致
"输入框接收不了大文本"。

现在输入 / 输出 / 模型类预览改为原生 `RichTextBox`（封装为 `Controls/CodeEditor.cs`，
保留占位符与主题配色），实测结果：

| 文本大小 | 旧实现（AntdUI.Input） | 现在（CodeEditor） |
| --- | --- | --- |
| 1 MB | 约 0.5 秒、+330 MB | 无卡顿、+约 12 MB |
| 3 MB | 约 1.5 秒、+908 MB | 无卡顿、+约 20 MB |
| 12 MB | 受 10 MB 上限截断 | 正常接收 |

同时为了避免超大文本拖慢界面，做了以下保护：

- 状态栏统计改为防抖（250 ms）并逐字符计数，不再每次输入都 `Split` 整段文本
- 语法着色超过 20 万字符自动跳过（纯色显示），着色时关闭重绘并一次性刷新
- JSON / XML 超过 3 MB 不再构建树视图，模型类生成上限 2 MB
